# Employee Management System

A simple and responsive Employee Management System built with Laravel. This project demonstrates Laravel MVC architecture, Eloquent ORM, routing, validation, and complete CRUD operations.

## 🚀 Features

- Add new employees
- View all employees
- Edit employee details
- Delete employees
- Form validation
- Success and error messages
- Responsive UI
- SQLite database
- Laravel MVC architecture
- Eloquent ORM
- Resource routing

## 🛠️ Tech Stack

- Laravel 13
- PHP 8.4
- Blade
- SQLite
- Eloquent ORM
- HTML5
- CSS3
- Git & GitHub

## 📋 Employee Fields

Each employee record contains:

- Full Name
- Email Address
- Phone Number
- Department
- Position

## 🏗️ Laravel Architecture

This project follows Laravel's MVC architecture:

```text
Model
  ↓
Employee.php
  ↓
Database

Controller
  ↓
EmployeeController.php
  ↓
CRUD Logic

View
  ↓
Blade Templates
  ↓
User Interface
```
